# nt13u_txm

Python-based measurement software for soft X-ray imaging experiments at NanoTerasu BL13U.

This project is a migration from a C# GUI-based software as a part of XAFS Measurement Control project (stored in local Git) at the Photon Factory, Japan,
toward a modular, script-friendly, and maintainable Python architecture.

## Status

This repository is currently maintained by a single developer.

It is primarily designed for in-house experimental use and is not yet intended
as a general-purpose or stable public package.

Interfaces, folder structures, and internal APIs may change without notice.

## Disclaimer

This software directly interacts with hardware devices.
Improper use may result in:

- Device lockups
- Acquisition conflicts
- Data loss

Use at your own responsibility.
